# Scene Library, Wagon Wheel, Select Bowler/Batter
- `?scene=wagon[&who=all][&bg=0]` stadium wagon wheel + shot map (uses recorded shot directions `e.ang`; score bar at bottom)
- `?scene=pick&kind=bowler` / `?scene=pickbat` select cards (ratings are derived from match stats, not stored)
- `?scene=lib&id=1..260` 260 named scenes on 13 data-bound templates; each scene has its own seeded colour, panel shape, entrance and font
- Stream tab card "Scene Library" copies the URLs. Tests: tests/scene-library.cjs
